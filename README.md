# PrepPilot - Interview Preparation Portal

A responsive interview preparation dashboard built using HTML, CSS, and JavaScript to help students organize their coding practice, study plans, and interview preparation.

## Features
- Responsive Dashboard
- Sidebar Navigation
- Progress Tracking
- Study Planner
- Task Management
- Activity Section
- Modern UI Design

## Technologies Used
- HTML5
- CSS3
- JavaScript
